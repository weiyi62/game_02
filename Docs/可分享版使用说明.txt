《黑白校园》Windows 可分享版

启动方式
1. 双击“黑白校园.exe”。
2. 如果 Windows 弹出安全提示，请确认文件来源后选择“运行”。
3. 游戏启动后可在设置中调整画面窗口大小。

操作
A / D：左右移动
K：跳跃
J：攻击
E：与门交互

系统要求
- Windows 10 或 Windows 11，64 位
- 建议使用支持 DirectX 11 或更高版本的显卡
- 解压后请保持“黑白校园.exe”和“黑白校园_Data”在同一文件夹内

分享注意
- 请完整分享整个“黑白校园_可分享版”文件夹，不要只发送 exe 文件。
- 可以将整个文件夹压缩成 zip 后发送给其他人。
- 第一次运行时，Windows Defender 或杀毒软件可能会进行安全检查。
